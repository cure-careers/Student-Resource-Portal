A measurement is incomplete unless the number includes the correct unit.

Answer: 6

Scientific Notation

Use powers of ten to write very large and very small numbers efficiently.

Standard Form

a × 10ⁿ

The coefficient a should be between 1 and 10. The exponent tells how many places the decimal moved.

  1. Move the decimal until the number is between 1 and 10.
  2. Count the number of places moved.
  3. Use that count as the exponent.

Examples

1,000,000 = 1.0 × 10⁶ 0.00000124 = 1.24 × 10⁻⁶ 1742 = 1.742 × 10³
Meaning check:
Positive exponent → number greater than 10
Negative exponent → number less than 1
Exponent of 0 → number between 1 and 10

Must Know for SPI

milli = 10⁻³
micro = 10⁻⁶

Micro is smaller than milli because its exponent is more negative.

High-Yield Rule

When the unit gets bigger, the number gets smaller.

When the unit gets smaller, the number gets bigger.

Complementary Metric Units

Some prefixes naturally pair because they represent matching large and small scales.

Core SPI Pair

MHz ↔ μs

If frequency is measured in megahertz, period is commonly reported in microseconds.

Millions of cycles pair with millionths of seconds.

Common Pairings

billions ↔ billionths (giga ↔ nano) millions ↔ millionths (mega ↔ micro) hundreds ↔ hundredths (hecto ↔ centi) tens ↔ tenths (deca ↔ deci)

Vocabulary Shortcut

Macro
Bigger or larger scale
Micro
Smaller or microscopic scale

Conversion Practice

Use the size of the units and the power of ten to determine where the decimal moves.

Rule 1: Larger Unit to Smaller Unit

Move the decimal point to the right.

1.5 L = 1500 mL

The unit became smaller, so the number became larger.

Rule 2: Smaller Unit to Larger Unit

Move the decimal point to the left.

500 mL = 0.5 L

The unit became larger, so the number became smaller.

How Many Places Should the Decimal Move?

Conversion FactorDecimal MovementExample
1,000 = 10³Move 3 placesL ↔ mL
1,000,000 = 10⁶Move 6 placesMHz ↔ Hz or s ↔ μs

SPI Memory Trick

Large unit → small unit: move right.

Small unit → large unit: move left.

Registry Trap

Do not rely only on memorizing decimal direction. First ask: Am I converting to a bigger unit or a smaller unit?

Bigger unit = smaller number.
Smaller unit = bigger number.
